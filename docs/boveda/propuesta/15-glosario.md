# 15. Glosario

| Término | Significado |
| --- | --- |
| Masa | Cantidad de materia de un objeto, en kg o t. No cambia según el lugar |
| Peso | Fuerza con que un cuerpo es atraído por un astro, en N. Peso = masa × g |
| Empuje | Fuerza que produce un motor cohete, en N o kN |
| Isp (impulso específico) | Eficiencia de un motor, en segundos. Mayor Isp significa más Δv por kilogramo de propelente |
| Relación empuje/peso (TWR) | Empuje dividido entre el peso del vehículo. Mayor a 1 significa que puede despegar |
| Δv (delta-v) | Cambio de velocidad que un vehículo puede lograr con su propulsión |
| LEO / MEO / GEO | Órbita terrestre baja, media y geoestacionaria |
| Efemérides | Posiciones calculadas de un cuerpo o nave en el tiempo |
| Horizonte de eventos | Frontera de un agujero negro; nada que la cruce puede volver a salir |
| Púlsar | Estrella de neutrones que emite pulsos de radiación al girar |
| HLS | Sistema de aterrizaje humano de Artemis (Starship y Blue Moon) |
| Predicción / reconstrucción | Trayectoria planeada antes del vuelo, frente a la estimada a partir de datos reales |
| Vercel | Plataforma de hosting y funciones serverless para desplegar aplicaciones web |
| Supabase | Plataforma de base de datos PostgreSQL, autenticación y almacenamiento |
| Apogeo | Punto de una órbita elíptica más alejado de la Tierra. |
| Perigeo | Punto de una órbita elíptica más cercano a la Tierra. |
| Velocidad de escape | Velocidad mínima para escapar de la gravedad de un cuerpo. Desde la Tierra es de unos 11,2 km/s. |
| Transferencia de Hohmann | Trayectoria de menor consumo de Δv para pasar de una órbita circular a otra. |
| Inyección translunar (TLI) | Maniobra que lanza la nave desde órbita terrestre hacia la Luna. |
| Sobrevuelo (flyby) | Paso cercano de una nave junto a un cuerpo, sin quedarse en órbita ni aterrizar. |
| Reentrada atmosférica | Regreso a la atmósfera a alta velocidad. Genera un calor intenso que el escudo térmico debe soportar. |
| Escudo térmico | Material que protege la cápsula del calor durante la reentrada. |
| Amerizaje | Aterrizaje de una cápsula en el mar, como el de las naves Orion al final de sus misiones. |
| Masa seca | Masa de un vehículo sin propelente. Es el mínimo que queda al terminar de quemar combustible. |
| Relación de masa (m₀ ÷ m\_f) | Cociente entre la masa inicial y la final. Aparece en la ecuación del cohete para calcular Δv. |
| Carga útil (payload) | Lo que transporta el vehículo: instrumentos, satélites o tripulación, sin contar su propio propelente. |
| Etapa | Sección de un cohete con sus propios motores y tanques, que se desprende al agotar su propelente. |
| Ventana de lanzamiento | Intervalo de tiempo en que un lanzamiento puede hacerse para alcanzar su objetivo. |
| SLS (Space Launch System) | Cohete pesado de la NASA que lanza la nave Orion en las misiones Artemis. |
| Orion | Nave tripulada de Artemis, con módulo de tripulación y módulo de servicio. |
| EVA (actividad extravehicular) | Trabajo que realiza un astronauta fuera de la nave, también llamado paseo espacial. |
| ISS (Estación Espacial Internacional) | Laboratorio orbital en órbita terrestre baja, habitado de forma continua desde el año 2000. |
| DSN (Deep Space Network) | Red de antenas de la NASA que se comunica con sondas y naves en el espacio profundo. |
| TRL (nivel de madurez tecnológica) | Escala de 1 a 9 que indica qué tan probada está una tecnología antes de usarse en vuelo. |
