# 13. Decisiones del proyecto

### Resueltas

- [x] Nombre del proyecto: **Astro Fuente**.
- [x] Plazo de entrega: **24 horas**.
- [x] Stack: **Vercel** (hosting y funciones) y **Supabase** (base de datos, almacenamiento); lenguaje **TypeScript** con Next.js.
